# 제 1회 랜딩톤 출품용

아이디어가 여러개라서 랜딩마다 `apps/<이름>/`으로 소스와 에셋을 나눠 둔 모노레포로 만들어봤습니다.

## 실행

```bash
pnpm install
pnpm dev       
#본인이 쓰는 패키지매니저 알아서. 근데 루트 스크립트는 **pnpm** 기준이고, lockfile도 `pnpm-lock.yaml`입니다.
```

## 작품

- **Meridian** — `apps/meridian` (가상의 브랜드 랜딩)
