# 회사 랜딩 기획 (MERIDIAN)

회사 소개 페이지다. 한 화면에는 하나의 장면만 있고, 스크롤은 그 장면을 재생한다. 마지막 장면에서 지구가 나타나고, 글로벌 지부를 돌려 본다.

회사 이름은 **MERIDIAN(메리디안)**이다. 개인 창립자 이름은 붙이지 않는다.
화면에 나오는 모든 문장은 `apps/meridian/src/copy.js`에 모아 두었다.

## 일곱 장면 (`01`–`07`)

각 장면은 화면 높이에 고정된다. 그 장면의 스크롤 길이 동안 재생되고, 끝나면 다음 장면으로 넘어간다.

| 순서 | 장면 | 재생 |
| --- | --- | --- |
| `01` | 입구 (`EnterScene`) | `MERIDIAN` 글자를 따로 끌어당긴다. 포인터가 다가가면 글자와 점들이 밀려난다. 두 문장이 차례로 나타나고, 스크롤하면 위로 빠진다. |
| `02` | 하는 일 (`PracticeStage`) | `BRAND`, `PRODUCT`, `DIRECTION`이 세로 원근 무대로 교대한다. 다이얼, 칸, 선이 포인터와 스크롤을 따라 움직인다. |
| `03` | 공간 화보 (`SpacesStage`) | 세 장의 건축·공간 화보(`CONCOURSE`, `PAVILION`, `HORIZON`)가 아코디언 트립틱 블레이드로 펼쳐진다. 열린 사진 위에서 마우스를 움직이면 광학 루페(`1.5×`, 홀드 시 `2.2×`)로 디테일을 들여다본다. |
| `04` | 대표 작업 (`WorkStage`) | `NOMAD`, `KIT`, `LEDGER`가 가로 덱으로 놓인다. 스크롤, 가로 드래그, 포인터 호버가 작업을 정돈해 보여 준다. |
| `05` | 포트폴리오 아카이브 (`ArchiveStage`) | **신규 포트폴리오 인덱스.** 6개 도시 스튜디오가 수행한 7편의 작업 목록(`SOLACE`–`VERTEX`)과 분야 필터(`ALL` / `BRAND` / `PRODUCT` / `SPACES`)가 놓인다. 스크롤 스윕 또는 행 위에 마우스를 움직이면 이동 속도에 반응해 기울어지는 **관성 플로팅 화보 릴**이 커서를 따라다니며 필름처럼 넘어간다. |
| `06` | 문 (`DoorScene`) | `SIX CITIES`가 켜지고 지우개 베일이 열린다. 단어가 걷히면 그 자리에서 지구가 떠오른다. |
| `07` | 지구 (`GlobeScene`) | 화면이 고정된다. 지구는 지부 카드와 연락이 남는 크기까지 다가온 뒤 멈춘다. 여섯 도시 점이 차례로 켜지고, 드래그로 도시를 앞으로 보낸다. `STYLE 1`–`STYLE 3`으로 지구의 얼굴을 바꾼다. |
